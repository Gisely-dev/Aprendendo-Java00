O QUE É O HELLO WORLD, DE VERDADE

Não é só um programa qualquer: é um ritual. Desde os anos 1970 (a expressão vem do livro clássico de C, de Kernighan e Ritchie), praticamente toda linguagem nova é apresentada assim.

Por que sempre esse mesmo exemplo? Porque ele testa, com o mínimo de código possível, se o ambiente inteiro está funcionando: o editor, o compilador e a forma de rodar o programa. Se "Hello, World!" aparece na tela, você sabe que a engrenagem toda está pronta para coisas mais complexas.

É o menor programa "completo" em Java: já tem classe, método principal e uma instrução de saída — os três blocos que aparecem em qualquer programa maior.

ONDE ISSO RODA

O código não roda "no ar" — ele passa por peças específicas, cada uma com um papel diferente:

1
O editor de códigoOnde você escreve o texto do programa. Pode ser um editor simples (VS Code) ou uma IDE completa (IntelliJ, Eclipse). Aqui o arquivo é só texto — nada é executado ainda.
2
O arquivo .javaSalvo em disco com o mesmo nome da classe pública (HelloWorld.java para class HelloWorld). Java exige essa correspondência exata.
3
O JDK instalado na máquinaO "Java Development Kit" traz o compilador (javac) e a JVM. Sem ele instalado, não existe onde compilar nem onde rodar o código.
JDK = ferramentas para desenvolver. JRE = ambiente para rodar. JVM = a máquina virtual que de fato executa o programa. O JDK inclui os outros dois.

O QUE ACONTECE NOS BASTIDORES

Entre escrever o código e ver o texto na tela, acontecem etapas concretas — nenhuma delas é mágica:

📝 HelloWorld.java — texto legível, feito para humanos lerem
↓ javac compila
⚙️ HelloWorld.class — bytecode, um código intermediário
↓ java inicia a JVM
💻 JVM lê e executa o bytecode
↓
🖥️ Console mostra: Hello, World!

Por que existe essa etapa intermediária (bytecode)? Porque o bytecode não é específico de nenhum sistema operacional. A JVM de cada sistema (Windows, Linux, Mac) sabe traduzi-lo para instruções que o processador daquela máquina entende. É esse o motivo do lema "escreva uma vez, rode em qualquer lugar".

public class HelloWorld { public static void main(String[] args) { System.out.println("Hello, World!"); } }

System.out é o canal de saída padrão do programa — o println manda o texto para esse canal, e é o terminal que o exibe na tela.

🏆 AGORA VOCÊ ENTENDE, NÃO SÓ RODOU

Você viu o que é o Hello World, onde cada peça mora no seu computador e o que acontece entre o código-fonte e o texto na tela: compilação para bytecode, execução pela JVM, saída no console.

Esse é o alicerce de qualquer programa Java que vier depois — só muda a complexidade do que está dentro do main.
