Seu Primeiro Programa em Java: o Hello World

Todo programador começa por aqui. Neste guia você vai entender, linha por linha, o que é esse tal "Hello World" e por que ele parece mais complicado em Java do que em outras linguagens.

Antes de começar: o que você precisa

Para escrever e rodar programas em Java, você precisa de duas coisas instaladas no seu computador:

  • JDK (Java Development Kit) — o "kit" que contém o compilador e tudo que é necessário para criar programas Java.
  • Um editor de código — pode ser algo simples como o VS Code, ou uma IDE completa como o IntelliJ IDEA ou Eclipse.
Dica: para verificar se o Java já está instalado, abra o terminal (ou prompt de comando) e digite java -version. Se aparecer um número de versão, está tudo pronto.

O código completo

Crie um arquivo chamado HelloWorld.java e escreva exatamente isto:

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
Atenção: o nome do arquivo precisa ser idêntico ao nome da classe pública, incluindo maiúsculas e minúsculas. Se a classe se chama HelloWorld, o arquivo tem que ser HelloWorld.java — nem helloworld.java, nem Hello.java.

Explicando linha a linha

Java é uma linguagem mais "verbosa" que outras — cada linha tem um papel específico. Vamos destrinchar:

public class HelloWorld {

Toda linha de código em Java precisa estar dentro de uma classe. Aqui estamos criando uma classe chamada HelloWorld. A palavra public significa que essa classe pode ser acessada de fora do arquivo.

public static void main(String[] args) {

Esta é a linha mais importante: o método main é o ponto de entrada do programa — é por aqui que o Java começa a executar o código. Cada palavra tem um motivo de estar ali:

PalavraO que significa
publico método pode ser chamado de fora da classe
statico método pertence à classe, não precisa criar um objeto para usá-lo
voido método não devolve nenhum valor
maino nome do método — o Java sempre procura por um método chamado exatamente assim
String[] argsuma lista de textos que podem ser passados ao programa na hora de executá-lo

System.out.println("Hello, World!");

Esta linha manda uma mensagem para a tela (a "saída padrão"). System.out representa a saída do console, e println ("print line") imprime o texto e pula para a linha seguinte.

} (duas vezes)

Cada chave de abertura { precisa de uma chave de fechamento } correspondente. A primeira fecha o método main, a segunda fecha a classe HelloWorld.

Por que tudo isso só para imprimir um texto? Porque Java é uma linguagem orientada a objetos e fortemente estruturada. Essa "verbosidade" inicial é o preço de uma organização que faz muita diferença em programas grandes — e você vai automatizar essa estrutura rapidamente.

Compilando e executando

Diferente de linguagens interpretadas, o Java precisa ser compilado antes de rodar. Isso transforma seu código-fonte (.java) em bytecode (.class), que a Máquina Virtual Java (JVM) entende.

No terminal, dentro da pasta do arquivo, digite:

javac HelloWorld.java

Isso gera um arquivo HelloWorld.class. Agora, para executar:

java HelloWorld
Repare: no comando javac você usa a extensão .java, mas no comando java para executar, usa só o nome da classe, sem extensão.

Se tudo deu certo, o terminal vai mostrar:

Hello, World!

Dica de ouro: Java é sensível a maiúsculas e minúsculas (case-sensitive). String é diferente de string, e main é diferente de Main.
